# Какой картой?

PWA, которая перед оплатой за пару секунд показывает, какой картой платить ради
максимального кешбэка — с учётом категорий месяца в каждом банке и остатка лимитов.
Требования — в [SPEC.md](SPEC.md).

Всё хранится только в браузере (`localStorage`): приложение не ходит в банки и
никуда не отправляет ваши категории и покупки.

## Быстрый старт

Нужен Node.js 20+. Зависимостей и сборки нет.

```bash
npm test        # тесты ядра: node --test
npm run serve   # http://localhost:8080/
```

`npm test` запускает `node --test` без аргументов: на Node 22+ форма
`node --test tests/` воспринимает каталог как файл и падает.

Для разработки нужен именно `tools/serve.mjs` (или любой сервер, который отдаёт
`.js` как `text/javascript`): ES-модули не загрузятся с `text/plain`.

## Установка на телефон

Откройте сайт по HTTPS (GitHub Pages) и добавьте на главный экран: в Safari —
«Поделиться» → «На экран „Домой“», в Chrome — меню → «Установить приложение».
После первого открытия приложение работает без сети.

На iPhone данные во вкладке Safari и в установленном приложении хранятся
раздельно: сначала установите, потом заполняйте категории — или перенесите
данные через «Ещё» → «Экспорт» / «Импорт».

## Релиз

1. Поднимите версию **в двух местах**: `VERSION` в `sw.js` и `APP_VERSION`
   в `src/version.js` (тест `tests/sw.test.js` проверит, что они совпадают).
   Без новой версии service worker не обновится и пользователи останутся
   на старом коде.
2. Новый файл в `src/`, `icons/` или корне добавьте в `ASSETS` в `sw.js` —
   иначе он не будет работать офлайн (это тоже проверяет `tests/sw.test.js`).
3. `npm test`, коммит, push в `main` — GitHub Pages опубликует сам.
4. Открытое приложение покажет «Доступна новая версия → Обновить»; вручную —
   «Ещё» → «Проверить обновления».

Иконки генерируются скриптом `node tools/make-icons.mjs`.

## Структура

```
index.html  styles.css  manifest.webmanifest  sw.js  icons/
src/app.js              оболочка: загрузка состояния, роутинг, события, тосты
src/version.js          версия приложения (совпадает с VERSION в sw.js)
src/core/               чистая логика без DOM
  match.js              поиск: магазин / алиас / MCC / группа, ё=е, регистр
  rank.js               ранжирование банков с valueCoef и лимитами
  limits.js             остатки лимитов из покупок месяца
  months.js             ключи месяцев, план категорий, копирование
  state.js              схема, валидация, миграции, хранение, экспорт/импорт
src/data/               предзаполнение: 7 банков, 28 MCC-групп, 64 магазина
src/ui/                 экраны, диалоги, экспорт/импорт, восстановление данных, обновления SW, хелперы
tests/                  node:test, фикстуры в tests/fixtures/
tools/serve.mjs         статический dev-сервер
tools/make-icons.mjs    генератор PNG-иконок без зависимостей
```

Правила слоёв: `src/core` не знает про DOM и `localStorage`; UI не считает
кешбэк сам и пишет в хранилище только через `src/ui/store.js`.
