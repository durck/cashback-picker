# Какой картой?

PWA, которая перед оплатой за пару секунд показывает, какой картой платить ради
максимального кешбэка — с учётом категорий месяца в каждом банке и остатка лимитов.
Требования — в [SPEC.md](SPEC.md).

Всё хранится только в браузере (`localStorage`): приложение не ходит в банки и
никуда не отправляет ваши категории и покупки.

## Быстрый старт

Нужен Node.js 20+. Зависимостей и сборки нет.

```bash
npm test        # тесты ядра: node --test
npm run serve   # http://localhost:8080/
```

`npm test` запускает `node --test` без аргументов: на Node 22+ форма
`node --test tests/` воспринимает каталог как файл и падает.

Для разработки нужен именно `tools/serve.mjs` (или любой сервер, который отдаёт
`.js` как `text/javascript`): ES-модули не загрузятся с `text/plain`.

## Структура

```
index.html  styles.css
src/app.js              оболочка: загрузка состояния, роутинг, события, тосты
src/core/               чистая логика без DOM
  match.js              поиск: магазин / алиас / MCC / группа, ё=е, регистр
  rank.js               ранжирование банков с valueCoef и лимитами
  limits.js             остатки лимитов из покупок месяца
  months.js             ключи месяцев, план категорий, копирование
  state.js              схема, валидация, миграции, хранение, экспорт/импорт
src/data/               предзаполнение: банки, MCC-группы, ~60 магазинов
src/ui/                 экраны и тонкие хелперы (format, router, store)
tests/                  node:test, фикстуры в tests/fixtures/
tools/serve.mjs         статический dev-сервер
```

Правила слоёв: `src/core` не знает про DOM и `localStorage`; UI не считает
кешбэк сам и пишет в хранилище только через `src/ui/store.js`.
